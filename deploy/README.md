# Пакет для бесплатного размещения (фоновые пуши)

## Что в папке
- `index.html` — ваш дневник (скопируйте актуальную версию сюда же, рядом с этими файлами)
- `manifest.json` — манифест PWA (внешний файл вместо data-URI)
- `sw.js` — Service Worker: офлайн-кэш + приём фоновых пушей
- `icon.svg` — иконка приложения
- `notify.html` — страница включения уведомлений (регистрирует SW, запрашивает разрешение)

## Где разместить бесплатно
Любой из вариантов даёт HTTPS, что обязательно для Service Worker:
1. **GitHub Pages** — создайте репозиторий, загрузите файлы, Settings → Pages → branch `main`.
2. **Netlify Drop** — зайдите на app.netlify.com/drop и перетащите папку (без регистрации не сохранится, с GitHub-аккаунтом — бесплатно навсегда).
3. **Vercel** / **Cloudflare Pages** — аналогично.

## Порядок
1. Положите свежий `index.html` в эту папку (рядом с `sw.js` и `manifest.json`).
2. Загрузите всю папку на хостинг.
3. Откройте сайт с телефона → дождитесь предложения «Добавить на главный экран» (или меню Chrome → «Добавить на главный экран»).
4. Откройте `/notify.html` → нажмите «Разрешить и включить пуши».

## Как это работает
- Пока вкладка открыта — работают все текущие напоминания (баннер + системные пуши), как раньше.
- Когда вкладка закрыта — работают **фоновые пуши**: Service Worker получает `push`-событие и показывает уведомление даже при закрытом приложении.

## Важно про серверные пуши (push с сервера в момент, когда приложение закрыто)
Браузер сам не знает, «пора кормить» — для этого нужен маленький сервер (или бесплатный сервис-шлюз), который раз в N минут шлёт push по подписке. Локальная логика напоминаний не может жить в SW, потому что он «спит». Если нужны пуши строго по расписанию при закрытом приложении — скажите, подготовлю серверный скрипт (бесплатно можно крутить на Vercel Cron / Cloudflare Workers). 

Сейчас сделано: SW установлен, офлайн работает, локальные уведомления через SW работают при открытой вкладке + Ready-страница включения. Это уже даёт «настоящие» пуши на устройстве при открытом приложении и каркас для фоновых.

## iOS
Пуши в установленном PWA поддерживаются с iOS 16.4: добавить на экран «Домой» → открыть с иконки → разрешить уведомления.
